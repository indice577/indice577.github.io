Méthode

Comment on mesure

Même méthode pour tous, données publiques uniquement, aucune opinion.

Qui est suivi

Les 577 sièges de l'Assemblée nationale, à partir des comptes que chaque député déclare sur sa fiche officielle, complétés par recherche quand la fiche est vide. Un compte n'est retenu que si son nom et sa présentation le rattachent clairement au député.

Quand

Un relevé par semaine, le dimanche soir, au même moment pour tout le monde. Le classement sort le lundi à 8 h. Chaque relevé est conservé : c'est ce qui permet de suivre les évolutions dans le temps.

Ce qu'on ne fait pas

Pas d'avis sur les idées, pas de note sur le fond, pas de compte privé, pas de message privé. On compare ce qui se voit publiquement, avec les mêmes règles pour tous les groupes.
